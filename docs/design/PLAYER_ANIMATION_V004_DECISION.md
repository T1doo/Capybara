# v004 动画样板后的制作选择

日期：2026-10-23。范围：ART3-100 技术试验的下一小样，不是最终生产路线批准。实测源码 `75bac70558257feb1088e0c9c84eb243cd41f7bb`；媒体、原始报告及其范围见 [64秒实景审阅包](../reviews/stage-03-v004/README.md)。

保留可编辑 Blender B 作为主要制作源，继续验证它能否同时支持预渲染序列与少量分层替换。理由是同一 v003 形体的 v004 后继已实际完成连续行走、低头和背侧转向，配件随明确结构变形，原控制源未被覆盖。该进展支持继续试验，但不足以锁定母图或运行方案：表面/脚掌仍需精修，当前375姿态绑定录制轨迹，不能直接推广为完整自由输入动画。

同源A/B第一段已实际完成，见[连续对照](../reviews/stage-03-v004/AB_REVIEW.md)：A为16张部分图层和二维足网格，B为相同前330tick的68张完整姿态；固定35°相机、下右144px参考、0.5显示比例、同Player轨迹及240速度。27.188/123.937秒是本机离线生成墙钟，未包含美术修整/工具编写；A无idle呼吸、B有，不能把此表外推为全面量产胜负。

下一批只沿少量2D分层加必要转体替换的候选运行方式做一个背侧转向样件，保留B为共同制作源及同源对照，不再扩建两套全量动作产线。当前A的五档低头替换和二维腿形还需时间连续性/接缝审查；自由起停、服装修改及紧凑图集后的运行成本也未验收。这是具体试验选择，不是最终路线锁定或艺术批准。

比较必须看实际实景连续片段中的肩颈/配件/脚掌接缝和接触，也记录新增动作/改配件的实际修改点、渲染或补面时间、纹理像素与缓存成本。二者都达不到既定绘本质量时继续修样，不因某条较差而选定另一条。预渲染源也可作为cutout的制作辅助，但不能把已经烘焙的完整帧重命名成分层动画来假装完成A。

以下问题进入正式动画组件前必须处理：墙边物理占地与长身体视觉越界、自由转向/起停的有界帧集、半透明及掠射覆盖、跨方向表面一致性。最终四独立方向、八向运动、idle/walk/pickup/soak、正式入口等范围仍按Stage3原PLAN执行；母图/路线/阶段状态均未晋级。
