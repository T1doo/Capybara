# 角色动画制作与运行路线

日期：2026-10-23。当前主实现为v005实时混合方案；ART3-100的母图/视觉/扩展验收尚未通过。当前证据见[v005运行与复现](../reviews/stage-03-v005/README.md)，前序对照见[v004审阅包](../reviews/stage-03-v004/README.md)。

保留Blender为共同可编辑制作源，角色运行采用有界上半身转面/动作替换和实时四足2D网格。原控制源不覆盖，角色外形/配件仍统一从同一源生成。v004按单条轨迹烘焙的375姿态保留作技术回归，不继续扩成生产动画库。

同源A/B第一段已实际完成，见[连续对照](../reviews/stage-03-v004/AB_REVIEW.md)：A为16张部分图层和二维足网格，B为相同前330tick的68张完整姿态；固定35°相机、下右144px参考、0.5显示比例、同Player轨迹及240速度。27.188/123.937秒是本机离线生成墙钟，未包含美术修整/工具编写；A无idle呼吸、B有，不能把此表外推为全面量产胜负。

背侧转向和实时位移候选现已完成，见[v005实景/复现](../reviews/stage-03-v005/README.md)：新64秒不读旧轨迹或帧银行，八个精确方向实际行走，四足按实际位置实时变形；84张透明裁边纹理约6.35MiB。上半身与配件保留原生遮挡，足层独立变形，角色拾取仍走原提交链。完整从源构建入口已实际执行，不依赖私有blend。

当前主要实现选择为Blender共同可编辑源、有界上半身转面/动作替换、实时四足2D网格；不再建设按录制轨迹生成完整角色帧的生产方式。旧B全帧工具留作参考/回归。这是技术取舍，ART3-100最终done仍须母图/绘本视觉/性能与服装修改证据；不能把相同材质的技术可用等同于美术批准。当前只有下右低头替换，16转面/5档低头、急反向腿形与脚掌仍待精修；其他朝向动作、soak与正式入口不算已完成。

比较必须看实际实景连续片段中的肩颈/配件/脚掌接缝和接触，也记录新增动作/改配件的实际修改点、渲染或补面时间、纹理像素与缓存成本。二者都达不到既定绘本质量时继续修样，不因某条较差而选定另一条。预渲染源也可作为cutout的制作辅助，但不能把已经烘焙的完整帧重命名成分层动画来假装完成A。

以下问题进入正式动画组件前必须处理：墙边物理占地与长身体视觉越界、自由转向/起停的有界帧集、半透明及掠射覆盖、跨方向表面一致性。最终四独立方向、八向运动、idle/walk/pickup/soak、正式入口等范围仍按Stage3原PLAN执行；母图/路线/阶段状态均未晋级。
