# Stage 3 home atmosphere probe

This is a four-view visual study in the existing `HomeVisualBlockout`, not an approved weather, day/night, or seasonal system. [`HomeAtmosphere2D`](../../game/scenes/visual_prototypes/home_atmosphere_2d.gd) exposes fixed `clear_morning`, `sunset`, `rain`, and `night` presets. The capture fixture keeps one actual home scene, camera, player position, AG4 candidate canvas and scale across all four views. It turns off the technical grid and uses reduced motion so the comparisons are stable.

The first real Compatibility GPU capture exposed a material mismatch: `CanvasModulate` darkened the bridge and player, but the unshaded painted ground/water/cottage shaders remained close to their morning colors. At one stable painted-ground sample the night-to-morning luminance ratio was **1.0**. That first run remains in ignored `build/art-pipeline/home_atmosphere_probe_20260923_first` as failed visual evidence.

The current prototype uses a world-only multiply overlay after the scene's painted materials, static seeded rain strokes, and two small additive window glows after the tint. It does not alter the game's shaders or formal entrance. Four actual 1280×720 OpenGL Compatibility screenshots and a per-file SHA manifest are in ignored `build/art-pipeline/home_atmosphere_probe_20260923_final`. [`check_home_atmosphere_capture.py`](../../tools/art/check_home_atmosphere_capture.py) verifies the exact script/image hashes and five fixed cross-material pixel landmarks. The final sampled night/morning luminance ratios are about 0.48 for painted ground, cottage wall, bridge, water and player; the window sample brightens instead. These samples prove only the named pixels in the fixed capture, not visual quality or every material.

Visual review of this prototype still finds substantial Stage 3 work: rain is static and does not wet ground/roof or change water/sky; the additive light is a localized glow without an approved lantern/window lighting design; dusk intensifies the existing wood color; coarse path, garden, shoreline and foliage forms remain visible. The four variants have one technical capture round, not the required three independent visual rounds. There is no runtime time-of-day clock, precipitation simulation, season content, formal scene integration, four-resolution or hardware matrix. Do not close ENV3-001/002, approve the environment, or mark ART3-102 complete from these screenshots.
