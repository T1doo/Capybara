## 目标与本阶段边界

交付可追踪、确定性、可持久化的建设和生态模型。世界至少三个视觉高度层级及坡道、台阶、桥梁等通行关系按原目标逐步落地，不能只改变贴图而忽略碰撞/可达层级。无需为了“真实”开发复杂连续流体求解器，但水不能只是 shader 或一个可随意点满的百分比。

建造至少覆盖预览、吸附、旋转/移动、合法性、提交、取消、移除回收和必要撤销保护；资源扣除、设施状态、碰撞/导航与存档保持一致。地形覆盖挖池、填土、修渠、岸边连接、合并/分割水体、保护区与关键通路。

水生态建立连通/灌溉、水质、生物多样性/舒适度及反馈规则，植物/鱼/来访生物的出现真实依赖环境。将桥、水车、码头连接到实际用途，不只独立动画。

提前提供后续消费者需要的最小 GameClock/环境条件接口、轻量目标/对话消费者和 NPC 设施导航/使用能力。NPC 至少能实际使用玩家建设的一项设施，不能用预摆贴图冒充响应。这不是提前完成 Stage 6 或 Stage 8。

**第一条玩家流程：**

```text
新游戏进入家园，发现干涸/退化水岸
→ 获得清晰、轻量的恢复目标
→ 探索并收集材料、取得必要工具
→ 清理、挖池/修渠、建设设施
→ 水体连通、灌溉改变
→ 种下适宜植物、改善栖息条件
→ 鱼/生物回归，NPC 使用设施
→ 获得社区反馈与新的建设/探索方向
→ 保存、退出、重开，所有有效变化仍在
```

以实玩测得约 20–30 分钟的有意义流程为中间验证，不靠等待、重复刷材料或开发者控制台凑时长。基础动作音效、操作反馈和相关 UI 在这里接入，不能全部留到 Stage 10。

**退出门：**从新档确实把干涸区域改造成可灌溉、有鱼、有植物、NPC 会使用的家园。至少 200 次混合编辑，含取消/拒绝/重复输入/移除/存档/卸载重载，无资源复制、状态损坏、通路软锁和导航失效。正式入口连续流程与保存重开有证据。完成后继续 Stage 6，不以此宣布 Goal 完成。

## 退出质量门

交付：

- 网格/半格建造。
- 家具、围栏、桥、道路、码头和灯具。
- 挖池、填土、修渠、岸边自动连接。
- 水体连通、灌溉、水质、生物多样性和舒适度。
- 可放置水生植物和生态设施。
- NPC/导航对建设变化的基础响应。
- 保存、撤销保护和非法操作检测。

退出标准：玩家可把一块干涸区域完整改造成可灌溉、有鱼、有植物、NPC 会使用的水边家园，200 次编辑后无状态损坏。

共同门见 [QUALITY_GATES](../../QUALITY_GATES.md)。本阶段任务与上述场景、运行、体验验收全部有适用证据才可晋级；历史报告不代表当前 HEAD 通过。
