## 目标与本阶段边界

在已有时间、水与库存模型上扩展翻土、播种、浇灌/灌溉、生长、收获、果树、花卉、水生植物及季节/湿度倾向；坚持非惩罚性节奏。跨日与卸载时的生长一致，不靠常驻每一株植物运行计时器。

接入工具升级、配方追踪、制作/烹饪、批量操作、商店/订单/交换/贡献和住宅内部/升级。配方、资源扣除、产物容量与解锁条件做事务验证，取消/容量不足不白扣材料。

先做能闭环且有差异的代表内容，再通过数据管线扩量；这里不要求一次生产全部 25–35 种植物，但最终范围不得被这一阶段样板数替代。

**退出门：**从采集到建造、种植、收获、制作、贡献/销售、住宅升级完整无阻断；键鼠/手柄 UI 能走完；跨日、离开区块、重开和旧档迁移通过；不能靠调试货币或赠送材料绕过主要成长。

## 退出质量门

交付：

- 作物、果树、花卉、水生植物。
- 季节/湿度适应和非惩罚性生长。
- 工具升级、配方、制作、烹饪和批量操作。
- 商店、订单、交换和社区贡献。
- 房屋内部、家具交互、住宅升级。
- 完整 UI 和手柄流程。

退出标准：从采集到建造、种植、收获、制作、销售/贡献和升级形成完整无阻断循环。
