## 目标与本阶段边界

这是当前产品焦点。按以下五组交付细化当前 PLAN；不再将“继续多做几类植物”作为唯一默认下一步。

**A. 同一整景的视觉标准。**围绕已锁定的家园方向，统一相机、弱透视、左上主光、接触阴影、色板、纹理颗粒、前中后景与交互可读性。64px 逻辑格和约 144px 主角参考尺度是技术起点，必须用实际场景验证；正式图不显示廉价格子和 debug 标记。

**B. 主角生产母图和小规模动画路线对比。**依据清洁链造型锚点制作真实 RGBA、稳定配件、脚底 pivot、可编辑分层或可重复渲染源。不要将已有技术 SVG 或不透明 AG1 直接标 PLAYER_MASTER 完成。

按原契约比较高分辨率 cutout + 少量替换帧，与 Blender 正交预渲染到 2D 序列。统一相机、游戏尺寸、姿态和代表动作；只做足以判定的 A/B，不建设两套全量流水线。比较实际观感、一致性、动作生产成本、性能和配饰/服装扩展，选定后集中生产。

本阶段至少交付四个独立方向、八方向运动演示，以及 idle、walk、pickup、soak 等代表动作；镜像不能导致配件错误。最终完整动作集仍包含快走、工具、挖掘、浇水、种植、钓鱼、坐下、睡觉、搬运与情绪动作，后续逐步补齐，不逐帧独立生图造成变脸。

**C. 一名主要 NPC 母图与 UI 组件样板。**NPC 要有独立剪影、设定和与主角一致的制作规格，但不宣称已有完整关系/日程。UI 建立面板/9-slice、按钮、图标、字体、焦点、选中、禁用和危险状态，覆盖现有暂停、背包、箱子、设置、交互提示及必要标题入口。任务/对话只做后续可复用组件，不以静态 UI 假装任务系统存在。

文字不烘焙进图片。四种目标分辨率与已有缩放/焦点矩阵仍需验证；正式显示不使用默认控件外观，状态不能只靠颜色区分。

**D. 环境整体统一与四种氛围。**保留现有房屋、桥、水车、码头、阔叶树作为基础。关闭 ENV3-001/002：木纹密度/对比/重复、屋瓦尺度、树冠层次/空隙/剪影、树干与接触关系必须在同一镜头中协调。三种 UV 偏移不算三套丰富树种，高分辨率纹理也不能掩盖粗糙形体。

菜地、水生植物、地面、道路和岸线只优先生产整景与下一段核心玩法必需的模块。水的动态/反射感、减少动态、遮挡与碰撞继续有效；SVG、Polygon2D 和程序生成不被一概禁止，以最终观感与可维护性判断。

同一真实场景输出晴天上午、黄昏、雨天、夜晚四套固定截图，以及角色实际尺寸、四底 Alpha、遮挡、UI 大字号/高对比证据。氛围预设可以先服务视觉门，但不等于完整天气或四季模拟。连续同类生成不能改善时换制作方法，不无限抽图；也不能达到轮次数就批准不合格内容。

**E. 正式入口整合。**视觉通过后，常规启动应使用同一套批准视觉资源，接入真实 Player、WorldZone、inventory、settings、save 和交互。VisualPreview 留作夹具，不继续成为新美术唯一入口；不另写第二套玩法。

从常规入口完成移动、拾取、工具、箱子、暂停、区域转换、保存退出和继续，恢复玩家与世界交互状态。旧灰盒可以作为技术 fixture 保留，但不能是展示新成果唯一的正式启动体验。不要仅改 scene 名和标题就称它为正式家园。

**Stage 3 退出门：**主角母图与路线、NPC 母图、统一环境/UI、四氛围和正式入口集成都有实机与自动回归证据；关键视图不存在粗糙占位、默认 UI、明显 AI 错误或风格冲突；所有必需艺术门完成。工具缺失导致强制 A/B 未做，要明确 blocked/未验证并继续独立工作，不能伪造比对或自行删除要求。

## 当前能力与差距

AG1是造型锚点，未锁定PLAYER_MASTER；A1家园、主屋/桥/水车/码头/树冠只在VisualPreview原型。生产入口仍为两区域灰盒；NPC/UI/动画A-B/四氛围/正式入口整合未通过。

## 退出质量门

重要资产按契约 §10.2 保留 4–12 个候选证据，主角、主要 NPC、地区地标和 UI 主界面至少两轮候选/改稿；AG1/A1 已锁定的方向复用真实历史，不为凑轮数重复抽图，后续轮次聚焦必要生产适配。

这一 Stage 提前确定最终美术质量，避免把廉价灰盒扩展到全游戏。

交付：

- 完全原创主角概念、母图和角色动画方案对比。
- 一个主要 NPC 母图。
- 家园视觉测试场景。
- 一套高品质地面、水岸、植物、房屋、家具和 UI 样板。
- 动态水面、光照、阴影、前景遮挡和环境粒子原型。
- 晴天上午、黄昏、雨天、夜晚四套固定截图。
- 资产生成、清理、登记、图集和导入自动化。

退出标准：测试场景已经明显达到非像素、高级绘本而非占位质量；截图中不存在明显 AI 错误、风格冲突、低分辨率或粗糙 UI。

共同门见 [QUALITY_GATES](../../QUALITY_GATES.md)。本阶段任务与上述场景、运行、体验验收全部有适用证据才可晋级；历史报告不代表当前 HEAD 通过。
