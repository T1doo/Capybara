# Original riverstone 9-slice UI frame — two manual vector rounds

Both frames are original editable SVG authored in this project without ImageGen, external images, fonts, remote references, scripts or another IP. Source files stay in `art/candidates`; no game asset path or approval is assigned. Their 512×512 Godot renders are true RGBA with border Alpha0. Exact source/raster hashes, A→B revision parent and statuses are in [CANDIDATE_MANIFEST](CANDIDATE_MANIFEST.csv). Technical PNGs and real-GPU screenshots live only in ignored `build/art-pipeline/ui_storybook_frame_v001`.

## A: first candidate and rejected layout assumptions

`panel_riverstone_a_v001.svg` introduced parchment with sage rim and four riverstone corners. `tools/render_svg_preview.ps1` required a 512px output; a 256px initial header rendered but failed the pipeline minimum, so the source was corrected to 512px before its hash was registered. A sandboxed render failed only on Windows Godot user logs/certificate access; the allowed local rerun actually passed. The first real Compatibility GPU pause/settings capture used 80px nine-slice texture margins; Godot also used those as content margins and compressed pause buttons. A 0px content override then let text/buttons overlap the rim, and 20px still overlapped the bottom corners. These failed/diagnostic captures are preserved separately as `gpu_a`, `gpu_a_margin_fix`, and `gpu_a_margin20`. A is not approved for product UI.

## B: restrained revision, still unapproved

`panel_riverstone_b_v001.svg` is a direct manual revision of A with thinner rings and smaller corner motifs. The build-only fixture explicitly uses 56px **texture slice** margins and 24px **content** margins. In the same actual home-preview Compatibility GPU scene, Chinese 1280×720 pause/settings captures `gpu_b_margin24` show readable controls without the A-layout collision. English 1280×800 at 150% `gpu_b_en150` keeps the pause actions readable and settings usable through the existing vertical responsive scroll; this is a visual sample, not a full four-resolution or physical-controller matrix. The existing flat Theme's focus/danger/button states remain in use. The temporary fixture's success log inherited an A label; the source PNG and build output directory identify the B review and are authoritative.

B is a **technical shortlist only**. It is still a fairly flat vector edge beside high-resolution painterly character/environment art, and no independent visual approval, 9-slice production resource, custom icon/font system, title/interaction prompt suite, accessibility color matrix or approved rights/promotion record exists. Do not copy either source or render to `game/assets` or mark CAP-0520 complete based on these two screens. The next step is a focused painted-surface/art-direction review plus all required resolution and input states before deciding whether to revise B or create a formal game-ready panel.
